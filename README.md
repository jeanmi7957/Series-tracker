# Series Tracker iPhone V2

Version PWA pensée pour iPhone. Elle peut être installée depuis Safari via « Partager → Sur l’écran d’accueil ».

## Important
Le dossier `/api/tmdb` doit être fourni par un hébergement avec un proxy sécurisé vers l'API TMDB et une variable `TMDB_TOKEN`. La clé ne doit pas être placée dans `app.js`.
